# 应用中心指南

应用中心是所有推演产物的画廊——你的会话生成的每个应用一张卡。

## 卡片读法

卡片一律 16:9，画面铺满整卡，字段内容压在底部浮层上：

```
┌──────────────────────────────┐
│                              │
│        [16:9 画面]           │  ← 按真实模型渲染的迷你应用
│                              │
│ ▩ 采买通                     │  ← 品牌图标（身份主题色）+ 产品名
│ 页面 4 角色 4 AI 3  ●closed 6/6│  ← 真实指标 + 门语言状态
└──────────────────────────────┘
```

- **画面不是摆拍**：缩略图由持久化五系统模型现场渲染（深色导航里是真实页面名）。未闭环的应用显示推演态和证据进度条，不摆假图。
- **状态 = 门语言**：`closed 6/6`（发布闭环全过，可打开操作）、`推演中`（还在收敛）、`blocked`（引擎停下来等你补充信息）。6/6 不是质量评分，是证据清点。

## 工具行

| 控件 | 作用 |
|---|---|
| 搜索框 | 按话题/产品名过滤 |
| 全部 / 推演中 / closed 6/6 / blocked | 门语言筛选卡（含各状态数量） |
| 服务健康点 | **点击展开**三服务详情：Node API / Python 推演引擎 / LLM 通道 |
| 最近更新 | 点击切换排序方向（最近 ↔ 最早） |

## 卡片操作

- **点自己的卡片** → 激活该会话并进入推演页，应用直接可操作
- **点别人的卡片** → 只读预览；想改先复刻（Fork）成自己的
- **悬停右上「…」→ 删除应用** → 删除该会话（幂等操作，误删的测试会话可以这样清理）
