# Prompt Pack

## 产品定位

- 产品名称：轻量 CRM 客户跟进系统
- 目标用户：个人销售
- 目标场景：管理客户档案、记录跟进、安排下次跟进、快速回顾近期互动

## 页面提示词

### 首页工作台

构建一个面向个人销售的 CRM 首页，包含今日待跟进、逾期提醒、未来跟进、最近更新客户、快速新建客户按钮。布局简洁，信息密度高，风格偏业务工具，中文占位。

### 客户列表

构建一个客户列表页，包含搜索框、状态筛选、标签筛选、下次跟进时间筛选、列表表格或卡片区。需要突出客户状态、最近跟进摘要和下一次跟进时间。

### 客户详情

构建一个客户详情页，左侧是客户基础资料和状态，右侧是按时间倒序排列的跟进时间轴，顶部保留新增跟进按钮。

### 跟进录入

构建一个在详情页侧边出现的跟进录入抽屉，字段包含跟进方式、内容摘要、结果、下一次跟进时间，强调快速提交与低打断。
