## 四、还有一条：演示域快路径在发残次品

同一天第一趟发的是「客户服务工单系统」，结果：

```
_recognize_domain(这道题)   → service_ticket   （关键词命中内置演示域）
_domain_fixture_fits_goal() → True             （相关性补丁放行——这题确实是工单系统）
stream 里 model.generate    → 0 次             （全程没调 LLM）
产出                        → 5 页 0 区块，连 blocks 键都不存在
```

那 4 个内置演示域是 page.blocks 上线**之前**冻结的。所以这不是「认错了域」
——是**认对了，但只有残次品可给**。08-04 加的那道相关性补丁挡不住这一类，
它只挡不相关的。
