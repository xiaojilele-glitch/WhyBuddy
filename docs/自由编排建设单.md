### O-1 `refine` / `repair` 不写 tools，永远跑全量
`真机撞到`

**现状**

```
# rehearsal_control.py 三处写 goal["tools"]
1661  confirmed["tools"] = ["spec"]        ← 新建轮按钮点火
2896  goal["tools"] = [hop]                ← 五个单跳工具
2950  goal["tools"] = list(preset.tools)   ← workflow 减菜

# 而 refine / repair 分支：
goal["text"] = original_goal              ← 只写 text，不写 tools
_handoff_factory(..., profile="full")   ← 直接全量
```

**后果** — 真机跑「社区图书馆借还书系统」落进精修路径，`capabilityPlan=product-rehearsal`， **43 步 195 秒一口气跑完全链**。控制面话术还停在单跳心智——收尾卡片问 「或是进入下一步的结构绑定?」，而 structure/semantics/assemble/bind 本轮全跑完了。

**要做** — 精修与修复也走逐跳：控制面按本轮指令挑 tools，而不是 `profile="full"` 一把梭。 精修的「改哪几段」本来就是控制面该判的事——这正是自由编排的用武之地。

> **判据（正 + 反）** 正：精修一次只改文案，只应跑 `spec`（或声明的那几跳）。 反：**断言执行过的 stages 等于本跳声明 tools 的展开**——只验「跑通了」的话，全量照样绿。

### O-3 子集选择缺依赖闭包：`bind` 不带 `assemble`
`跑代码确认`

**现状** — `expand_tools` 里 `structure` 带三件（structure + semantics + assemble）， `bind` 只带自己。于是 `['spec','pages','bind']` 让 `model` 保持 `None`， `bind_pages(pages, None)` 每页 `'NoneType' object is not subscriptable`， 被 fail-open 咽掉，**ok=0、不抛异常**。

**为什么现在必须修** — 20 个固定原型×设备组合**全部安全**——这个洞只在自由编排上。 让模型挑子集的那一刻，依赖闭包就从「不需要」变成「必需品」： grok 的脚本里顺序是作者写死的，子集选择继承不到这个保证。

**要做** — `bind` 隐含 `assemble`。 **不要在 bind_pages 里加判空**——那只是把静默失败换一种静默法。

> **判据（变异）** 对任意 tools 子集断言：`bind` 在场 ⇒ `assemble` 在场。**把闭包删掉必须变红。**

- slide-rule-python/services/capability_plan.py · expand_tools

### O-7 注册即通过 → 桩 host 干跑闸
`对照 validate.rs`

**差距** — grok `validate.rs`：**用真引擎 + 桩 host 干跑一遍**。 `SpawnAgent` 返回罐头输出、scratch 文件返回 stub，编排逻辑全真， 跑不通就在花掉任何 agent 调用之前 fail。 WhyBuddy `register_workflow` 只校验：名字 kebab-case、stages 非空、stages 不重复。 **没有任何东西证明这份 stages 跑得起来。**

### O-8 journal + 重放校验，中断续跑才敢开
`对照 journal.rs`

**差距**

grok `JournalEntry` 带 `seq` + `req_hash`，重放时校验 「脚本发出的调用跟记录的一致」，不一致直接报：
```
replay divergence at seq {seq}: the script issued a different
call than the recorded run — nondeterministic or edited mid-run
```
WhyBuddy 的 `session_events` 只是 wire 形状（职责不同，这没问题）， 真正对应 journal 的那层还没有。

**什么时候必须做** — **一旦允许逐跳中断后续跑**。没有它，改了编排再续跑会安安静静接在错的地方—— 而逐跳编排天生就是「跑一半停下来问用户」的形态。

> **判据** 记录一轮，改动编排后重放：**必须报 divergence，不许静默接上**。
